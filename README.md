## 5.1 Подробнее о списках (list)

`list` — изменяемая упорядоченная последовательность. Методы:

| Метод | Что делает |
|-------|-----------|
| `append(x)` | добавляет элемент в конец |
| `extend(iterable)` | добавляет все элементы из итерируемого объекта |
| `insert(i, x)` | вставляет элемент на позицию `i` |
| `remove(x)` | удаляет первый элемент со значением `x` (`ValueError`, если нет) |
| `pop([i])` | удаляет и возвращает элемент (по умолчанию последний) |
| `clear()` | удаляет все элементы |
| `index(x[, start[, end]])` | индекс первого элемента `x` |
| `count(x)` | сколько раз `x` встречается |
| `sort()` | сортирует на месте |
| `reverse()` | разворачивает на месте |
| `copy()` | поверхностная копия |

Методы `insert`, `remove`, `sort` и другие меняют список и возвращают `None`.

**Стек (LIFO):** `append` + `pop`. **Очередь (FIFO):** лучше `collections.deque` с `popleft()`, потому что `list.pop(0)` медленный: все элементы сдвигаются.

### List comprehensions

Синтаксис: `[выражение for элемент in последовательность if условие]`, условие необязательно. Допускается несколько `for` и вложенные comprehensions (например, транспонирование матрицы).

```python
evens = [n for n in range(1, 11) if n % 2 == 0]
```

Это короткая запись цикла `for` с `append`. Когда логика сложная, обычный цикл читается лучше.

## 5.2 Оператор `del`

Удаляет элемент по индексу или срез, в отличие от `pop` ничего не возвращает: `del a[0]`, `del a[2:4]`, `del a[:]`. Умеет удалять и переменные целиком.

## 5.3 Кортежи (tuple)

`tuple` — неизменяемая упорядоченная последовательность. Присваивание `point[0] = 99` даёт `TypeError`.

- **Упаковка и распаковка:** `t = 1, 2, 3` и `x, y, z = t`.
- **Кортеж из одного элемента** пишется с запятой: `("one",)`.
- Сам кортеж неизменяем, но изменяемый объект внутри (например, список) менять можно.
- Кортеж можно использовать как ключ словаря, список нельзя.

## 5.4 Множества (set)

Неупорядоченная коллекция уникальных элементов. Быстрая проверка вхождения `in`, удаление дублей.

| Операция | Запись | Смысл |
|----------|--------|-------|
| объединение | `a \| b` | элементы из `a` или `b` |
| пересечение | `a & b` | элементы в обоих |
| разность | `a - b` | в `a`, но не в `b` |
| симметричная разность | `a ^ b` | в одном из двух, но не в обоих |

Пустое множество создаётся только через `set()`: `{}` создаёт пустой `dict`. Есть и set comprehension: `{c for c in "abracadabra" if c not in "abc"}`.

## 5.5 Словари (dict)

Пары «ключ -> значение». Ключи уникальны и должны быть неизменяемыми (хешируемыми): строки, числа, кортежи. Значения могут быть любыми.

- `d[key]`: значение (`KeyError`, если ключа нет), `d.get(key, default)`: безопасное чтение.
- `d.keys()`, `d.values()`, `d.items()`: представления для обхода.
- `del d[key]`, `key in d`.
- Создание: `dict([...пары])`, `dict(a=1, b=2)`, dict comprehension `{n: n**2 for n in (2, 4, 6)}`.
- Порядок вставки сохраняется (с Python 3.7).

## 5.6 Приёмы работы с циклами

- `for k, v in d.items()`: обход словаря.
- `enumerate(seq)`: индекс и значение.
- `zip(a, b)`: параллельный обход нескольких последовательностей.
- `reversed(seq)` и `sorted(seq)`: обратный и отсортированный обход без изменения исходного.

## 5.8 Сравнение последовательностей

Последовательности сравниваются лексикографически: поэлементно, пока не найдётся первое различие. `(1, 2, 3) < (1, 2, 4)` даёт `True`.

## Сводная таблица

| | `list` | `tuple` | `dict` | `set` |
|---|---|---|---|---|
| Пример | `[1, 2]` | `(1, 2)` | `{"a": 1}` | `{1, 2}` |
| Изменяемость | да | **нет** | да | да |
| Порядок | да | да | да (с 3.7) | нет |
| Дубликаты | да | да | ключи уникальны | **нет** |
| Доступ | индекс | индекс | ключ | только `in` |
| `in` | медленно | медленно | быстро | быстро |

## Какую структуру выбрать

- Нужен порядок и изменения -> `list`
- Неизменяемые данные, фиксированная запись -> `tuple`
- Доступ по имени (ключу) -> `dict`
- Уникальность и быстрая проверка вхождения -> `set`
